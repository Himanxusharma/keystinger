KeyStinger Extension

100% On-Device Privacy Guarantee

Effective Date: August 13, 2026

1. Overview & Privacy Commitment

KeyStinger is an open-source, privacy-first Chrome Extension designed for AI developers to validate API key credentials, discover models, inspect network traffic, and manage credentials securely.

Our Promise: KeyStinger operates 100% on your local device. We do NOT operate intermediate cloud backend proxy servers, we do NOT collect personal data, and we do NOT track user behavior or send telemetry.

2. Information Processing & Security

Local AES-256 WebCrypto Encryption: All saved API keys are encrypted locally using 256-bit WebCrypto AES-GCM algorithms before writing to chrome.storage.local. Plaintext keys are never stored on disk.

Direct Browser Fetch: All validation API calls originate directly from your Chrome browser to official provider API endpoints (e.g., api.openai.com, api.anthropic.com, generativelanguage.googleapis.com). KeyStinger has zero middleman cloud servers.

3. Chrome Extension Permissions Justification

Permission Purpose & Justification
storage Required to store WebCrypto AES-GCM encrypted API key records locally on disk (chrome.storage.local).
contextMenus Allows right-clicking selected API key text on any webpage to validate credentials with KeyStinger.
alarms Registers a background timer (chrome.alarms) for periodic health checks on saved credentials.
host_permissions Enables direct client-side fetch() HTTP requests from the user's browser to official AI provider API endpoints.

4. Zero Analytics Policy

We do not use Google Analytics, tracking cookies, or external telemetry scripts. Your credentials and usage remain completely private on your device.
